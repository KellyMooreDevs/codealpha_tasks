# CodeAlpha Tasks — AI Internship

Submission repository for the CodeAlpha Artificial Intelligence internship.
Two of the four listed tasks were completed, as required (minimum 2–3).

## Completed Tasks

### ✅ Task 1: Language Translation Tool
`Task1_Language_Translation_Tool/`
A web-based translation tool — type text, pick source/target languages, get an instant translation. Uses the free MyMemory translation API (no signup required). Includes the optional copy-to-clipboard and text-to-speech features.
See `Task1_Language_Translation_Tool/README.md` for details and a live demo link once deployed.

### ✅ Task 2: Chatbot for FAQs
`Task2_FAQ_Chatbot/`
An FAQ chatbot for study-abroad questions (documents, visas, flights, etc.). Preprocesses user input and matches it to the closest FAQ using TF-IDF + cosine similarity. Includes the optional chat UI, served via a small Flask API.
See `Task2_FAQ_Chatbot/README.md` for setup and run instructions.
